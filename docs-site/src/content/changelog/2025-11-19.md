**`rookery-go` 2.0.0.** Every method now takes a `context.Context` as its
first argument, so cancelling a context cancels the request in flight
rather than abandoning a goroutine that carries on regardless.

```go
// Before
client.Events.Publish(&rookery.EventParams{ /* … */ })

// After
client.Events.Publish(ctx, &rookery.EventParams{ /* … */ })
```

**Errors are typed.** `*rookery.APIError` carries `StatusCode`, `Code` and
`RequestID`, so retry logic no longer has to match on message strings.

```go
var apiErr *rookery.APIError
if errors.As(err, &apiErr) && apiErr.StatusCode == 429 {
	// back off
}
```

**Verification returns the parsed event.** `VerifyWebhook` used to return
only a boolean, which meant every caller verified and then parsed the same
bytes a second time.

Version 1 continues to receive security fixes until **2026-11-19**. There
are no server-side changes here — a v1 client and a v2 client talk to the
same API.
