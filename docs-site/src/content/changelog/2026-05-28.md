**Replay a delivery at a local URL.** The fastest development loop we have
shipped: take a real delivery and re-send it at your laptop as many times
as you like, with the original payload, headers and signature.

```bash
rookery deliveries replay dl_7ha20qsz13 --to http://localhost:3000/webhooks
```

It never touches the real subscriber, so it is safe against production
deliveries. Reproducing a customer's failure is now a single command
rather than an afternoon of guessing at payloads.

Batch form, for after an outage:

```bash
rookery deliveries list --status exhausted --since 1h \
  --replay-to http://localhost:3000/webhooks
```

**`--json` on every command.** Previously only `list` supported it.

**Fixed:** `rookery listen` left its temporary endpoint registered when
the process was killed rather than interrupted. The next `listen` now
cleans up anything left behind.
