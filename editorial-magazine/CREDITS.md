Covers are 1200px on the long side, in-story figures 900px — roughly
twice their display size, so they stay sharp on a high-density screen.
1.5 MB for the set of fifteen, which is about 100 KB each: the same
per-photograph budget as the other templates, on a template that is
genuinely about photography and so carries nearly twice as many.

Each alt text describes the photograph that is actually there. Worth
saying because they were written before the pictures were chosen, and
six of them had to be corrected afterwards.

## Type

[Fraunces](https://fonts.google.com/specimen/Fraunces) by Undercase
Type for headlines and the masthead, and
[Newsreader](https://fonts.google.com/specimen/Newsreader) by Production
Type for body text. Both are served through `next/font`, which
downloads them at build time and self-hosts them — so the finished site
makes no request to Google.

## Everything else

The masthead, the print-edition cover, the contributor avatars, the
drop caps and the rules are all drawn in CSS inside this template.
There are no other third-party assets.
