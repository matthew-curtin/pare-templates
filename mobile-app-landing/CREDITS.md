## Type

[Manrope](https://fonts.google.com/specimen/Manrope) by Mikhail Sharanda,
served through `next/font`, which downloads it at build time and
self-hosts it — so the finished site makes no request to Google.

## Everything else

The phone mockup, the hypnogram, the logo, the download badges, the
icons and the illustrations are all drawn in CSS or inline SVG inside
this template. There are no other third-party image assets.

The download badges are deliberately **not** Apple's or Google's
official store artwork — those are trademarks. If you ship a real app,
replace them with the badges each store provides and follow their
guidelines.
